# 미다스의원 홈페이지 (MIDAS Aesthetic Clinic)

미다스의원 인스파이어리조트점 (구 선이고은 성형외과) 리뉴얼 홈페이지입니다.
기존 nosekorea.com의 세포치료 관련 내용을 모두 빼고, 프리미엄 성형외과 콘셉트로 새로 디자인했습니다.

## 디자인 방향 (v5 — Deep Emerald & Pewter)
- 레퍼런스(유스앤영, 다움성형외과)의 고급 레이아웃 구조만 참고, 웜톤은 제거
- 컬러: 딥 에메랄드(#0E2A25) 다크 섹션 · 스톤 화이트(#EEF0EC) · 퓨터 실버(#A7B0A9/#C4CCC5) · 강조 에메랄드(#1F5C4E). 호텔 로비 같은 조용한 럭셔리
- 서체: Inter Tight(가는 웨이트 대형 헤드라인 + 볼드 강조), Noto Sans KR, 영문 대문자 트래킹 라벨
- 구성: 투명→화이트 고정 헤더(드롭다운) → 풀스크린 메인 슬라이더(진행바·탭) → 3단 특징 블록 → 시그니처 프로그램 카드 3종 → 풀블리드 영상 섹션 → 브랜드 스테이트먼트 → 진료안내(좌측 카테고리·우측 리스트) → 원장 2분할 → International(도시 시계) → 공간 그리드 → 빠른 상담 폼 + 오시는 길 → 푸터, OPEN/CLOSE 퀵메뉴

## 구성
- `index.html`: 원페이지 사이트(CSS·JS 포함, 별도 빌드 없음)

## 기존 사이트에서 제외한 항목
- 세포 메뉴 전체 (세포연구, 암 유전자 검사, 중금속 검사, DNA 분석, 면역분석, 피부/탈모, 근골격 통증치료)
- 줄기세포 유방 확대술, 줄기세포 유방 재건술
- PMRP, 슈퍼 PRP, 더마셀리프팅
- "세포연구의 선두주자" 배너, BL Stem Medical Center 팜플렛 링크, 파나셀 로고 링크

## 오픈 전 해야 할 일
1. **사진 교체**: 메인 슬라이드 3장(`.slide .bg`), 시그니처 카드 3장(`.card .bg`), 원장 프로필(`.dir-photo`), 공간 5장(`.sp .bg`)은 지금 그래픽 자리표시자입니다. 위치마다 HTML 주석으로 교체 방법을 적어 두었습니다.
2. **상담 신청 폼**: `index.html` 하단 스크립트의 `ENDPOINT`에 접수용 서버나 폼 서비스 주소를 넣어야 실제로 전송됩니다. 비어 있으면 전화 문의 안내만 표시됩니다.
3. **진료시간 확인**: 기존 사이트에 평일 19:00(본문)과 18:30(푸터)이 섞여 있어 18:30으로 넣었습니다.
4. **영상**: 'Midas Film' 재생 버튼은 모달만 열립니다. YouTube 주소를 받으면 임베드합니다.
5. **메신저 QR**: 카카오톡·WhatsApp·WeChat QR 이미지를 받으면 연락처 영역에 추가해 주세요.
6. **지도**: 아직 없습니다. 오시는 길 영역에 카카오맵이나 네이버지도 퍼가기 코드를 넣어 주세요.
7. **다국어(EN/CN)**: 상단 KR/EN/中文 토글은 자리만 있고 아직 연결되지 않았습니다.

## 의료광고 관련
과장 표현, 전후 사진, 후기는 넣지 않았고, 푸터에 부작용 고지 문구를 넣었습니다. 게시 전 의료광고 심의 대상인지 확인해 주세요.
