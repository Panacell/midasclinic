# 미다스의원 홈페이지 (MIDAS Aesthetic Clinic)

미다스의원 인스파이어리조트점 (구 선이고은 성형외과) 리뉴얼 홈페이지입니다.
기존 nosekorea.com의 세포치료 관련 내용을 모두 빼고, 프리미엄 성형외과 콘셉트로 새로 디자인했습니다.

## 구성
- `index.html`: 원페이지 사이트(CSS·JS 포함, 별도 빌드 없음)
- 섹션: 메인 비주얼 → 진료 철학 → 시그니처(코 재건) → 진료안내(탭) → 대표원장 → 공간 → 상담 과정 → 오시는 길·상담 신청 → 푸터

## 기존 사이트에서 제외한 항목
- 세포 메뉴 전체 (세포연구, 암 유전자 검사, 중금속 검사, DNA 분석, 면역분석, 피부/탈모, 근골격 통증치료)
- 줄기세포 유방 확대술, 줄기세포 유방 재건술
- PMRP, 슈퍼 PRP, 더마셀리프팅
- "세포연구의 선두주자" 배너, BL Stem Medical Center 팜플렛 링크, 파나셀 로고 링크

## 오픈 전 해야 할 일
1. **사진 교체**: 원장 프로필(`.doc-photo`), 병원 공간 5장(`.gallery .fill`)은 지금 그래픽 자리표시자입니다. 위치마다 HTML 주석으로 교체 방법을 적어 두었습니다.
2. **상담 신청 폼**: `index.html` 하단 스크립트의 `ENDPOINT`에 접수용 서버나 폼 서비스 주소를 넣어야 실제로 전송됩니다. 비어 있으면 전화 문의 안내만 표시됩니다.
3. **진료시간 확인**: 기존 사이트에 평일 19:00(본문)과 18:30(푸터)이 섞여 있어 18:30으로 넣었습니다.
4. **메신저 QR**: 카카오톡·WhatsApp·WeChat QR 이미지를 받으면 연락처 영역에 추가해 주세요.
5. **지도**: 약도는 그래픽입니다. 필요하면 카카오맵이나 네이버지도 퍼가기 코드로 바꿔 주세요.
6. **다국어(EN/CN)**: 아직 없습니다.

## 의료광고 관련
과장 표현, 전후 사진, 후기는 넣지 않았고, 푸터에 부작용 고지 문구를 넣었습니다. 게시 전 의료광고 심의 대상인지 확인해 주세요.
