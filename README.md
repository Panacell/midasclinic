# 미다스의원 홈페이지 (MIDAS Aesthetic Clinic)

미다스의원 인스파이어리조트점 (구 선이고은 성형외과) 리뉴얼 홈페이지입니다.
기존 nosekorea.com의 세포치료 관련 내용을 모두 빼고, 프리미엄 성형외과 콘셉트로 새로 디자인했습니다.

## 디자인 방향 (v7 — International · Bright)
- 콘셉트: "Beauty, without borders." 국제적이고 활기찬 프리미엄 성형외과
- 컬러: 화이트 바탕 · 라군 틸(#1A9A8B / 딥 #0F6F65) · 애프리콧 포인트(#FF9B6A) · 잉크(#10232B) · 민트 미스트(#F1F7F6)
- 서체: Plus Jakarta Sans(모던 산세리프 헤드라인) + Instrument Serif 이탤릭 강조 + Noto Sans KR
- 레이아웃: 매거진식 비대칭(풀블리드 히어로, 지그재그 시그니처, 메뉴판형 진료 목록, 원장 인용 겹침, 가로 드래그 갤러리, 틸 블록 예약 섹션)
- 이미지 자리: 낮의 도시 스카이라인·바다·대리석·보케를 캔버스로 그려 둠. `<canvas class="scene">`를 `<img>`로 바꾸면 실제 사진으로 교체

## 구성
- `index.html`: 원페이지 사이트(CSS·JS 포함, 별도 빌드 없음)

## 기존 사이트에서 제외한 항목
- 세포 메뉴 전체 (세포연구, 암 유전자 검사, 중금속 검사, DNA 분석, 면역분석, 피부/탈모, 근골격 통증치료)
- 줄기세포 유방 확대술, 줄기세포 유방 재건술
- PMRP, 슈퍼 PRP, 더마셀리프팅
- "세포연구의 선두주자" 배너, BL Stem Medical Center 팜플렛 링크, 파나셀 로고 링크

## 오픈 전 해야 할 일
1. **사진 교체**: 히어로, 시그니처 3장, 라운지, 원장 프로필, 갤러리 5장, 예약 배경이 캔버스 그래픽입니다. 각 `.ph` 안의 `<canvas>`를 `<img>`로 바꾸면 됩니다.
2. **상담 신청 폼**: `index.html` 하단 스크립트의 `ENDPOINT`에 접수용 서버나 폼 서비스 주소를 넣어야 실제로 전송됩니다. 비어 있으면 전화 문의 안내만 표시됩니다.
3. **진료시간 확인**: 기존 사이트에 평일 19:00(본문)과 18:30(푸터)이 섞여 있어 18:30으로 넣었습니다.
4. **메신저 QR**: 카카오톡·WhatsApp·WeChat QR 이미지를 받으면 연락처 영역에 추가해 주세요.
5. **지도**: 아직 없습니다. 오시는 길 영역에 카카오맵이나 네이버지도 퍼가기 코드를 넣어 주세요.
6. **다국어(EN/CN)**: 상단 KR/EN/中文 토글은 자리만 있고 아직 연결되지 않았습니다.

## 의료광고 관련
과장 표현, 전후 사진, 후기는 넣지 않았고, 푸터에 부작용 고지 문구를 넣었습니다. 게시 전 의료광고 심의 대상인지 확인해 주세요.
